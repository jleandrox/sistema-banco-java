# 🏦┃SISTEMA BANCÁRIO EM JAVA


  💰 Simulação de operações bancárias         
  🔁 Uso de While e Switch                   


---

## 📌┃SOBRE O PROJETO

Este projeto foi desenvolvido com o objetivo de praticar estruturas fundamentais da linguagem **Java**, utilizando um sistema bancário simples via console.

A aplicação simula operações básicas de uma conta bancária, permitindo ao usuário interagir com o sistema de forma contínua até decidir encerrar.

---

## 🕹️┃FUNCIONALIDADES

➤ 📥 **Depósito (recebimento de valor)**  
➤ 📤 **Transferência (envio de valor)**  
➤ 📊 **Consulta de saldo**  
➤ 🚪 **Encerramento do sistema**

---

## ⚙️┃COMO FUNCIONA

O sistema utiliza um menu interativo baseado em:


🔁 While → mantém o programa em execução
🔀 Switch → controla as opções do menu


A cada interação, o usuário escolhe uma opção e o sistema executa a operação correspondente.

---

## 🏁┃EXEMPLO DE MENU


1 - Consultar saldo
2 - Receber valor
3 - Transferir valor
4 - Sair


---

## ⚠️┃REGRAS DO SISTEMA


✔️ O saldo é atualizado a cada operação
✔️ Não é possível transferir valores maiores que o saldo disponível
✔️ O sistema continua rodando até o usuário escolher sair
